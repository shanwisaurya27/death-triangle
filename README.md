# The Death Triangle: A Chronological Retrospective (2142–2151)

# Introduction

The Death Triangle (2142–2151) remains one of the most devastating ideological and territorial conflicts in modern history. Fought across three heavily contested strategic nodes—the Oasis Ring (Sector 4), the mineral-rich Cocytus Asteroid Belt, and the planetary gateway of Veridia Prime—the war redrew geopolitical boundaries, crippled orbital trade, and fundamentally changed how automated warfare and orbital defense are conducted.
